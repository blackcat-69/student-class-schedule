# Project Brief

## Project Identity

Student Class Schedule

## One-Sentence Concept

A browser-local weekly class schedule where students can view, add, edit classes and reminders, filter by day, and have data persist in localStorage.

## Target User

Students managing their weekly class schedule

## User Goal

See weekly view of classes, add/edit classes and reminders, filter by day or class, with a clean, easy-to-navigate interface

## Build Shape

Browser-local tool

## Shape Confirmation

Confirmed

## Version-One Success

Working weekly schedule view with add/edit/delete for classes and reminders, day/class filters, data persists in localStorage, responsive and clean UI

## Now / Later / Never

### Now

- Weekly grid view (Mon–Sun)
- Add/edit/delete classes (name, time, day, color)
- Add/edit/delete reminders per class
- Filter by day and class name
- localStorage persistence
- Responsive, mobile-friendly layout

### Later

- Recurring reminders
- Export/import schedule
- Dark mode
- Multiple week view

### Never

- Login/auth
- Backend/database
- Multi-user sync
- Payments
- Live API integration

## Assumptions

- Single browser, single user
- Data stored in localStorage only
- No server needed
- Desktop and mobile browsers supported

## Proof Target

GitHub + Vercel deployment showing working schedule with persistent data after refresh
